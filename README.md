# Radar (Spider) Charts with Python and Matplotlib

Python/Matplotlib script drawing radar (spider) chart subplots of morphometric variables, demonstrated on Mariana Trench data. Reusable scientific-plotting example.

## Scripts

- `radar_chart_subplot.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `seaborn`.

```
pip install matplotlib numpy pandas seaborn
```
